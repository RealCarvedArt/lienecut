# Independent discovery security review

Project: LieneCut. Reviewer: security_review agent, separate from implementation. Scope: read-only application/build/USB source plus dependency audit and mocked protocol reproduction. This is a discovery review, not a passed phase-7 audit.

Gate verdict: FAILED. Findings SEC-01 through SEC-07 are documented in threat-register.md.

Confirmed reproduction: calling PixCut.printAndCut with an already-aborted signal and fake status/create/upload/cancel methods produced [create, upload, upload, cancel]. No device was used. Source reads the signal only after job creation and both uploads (src/protocol.js printAndCut). The UI also awaits JPEG encoding before reading mutable cut bytes (src/app.js print handler), permitting mismatched image/path under concurrent editing.

Dependency audit: 9 high and 1 moderate in development tooling, principally Puppeteer dependencies. These packages are not the browser runtime bundle, but the harness does not waive development supply-chain findings.

Independent privacy review: no runtime upload/analytics found; raw filenames/device payloads enter visible logs, Clear leaves them, and printer retention is unknown. Inventory added; behavior findings remain open.

Independent UX review: browser evidence and all findings are in ../ux/personas-and-journeys.md. No accessibility sign-off.

Existing test suite: 10/10 passed. Build: success, approximately 46 KiB self-contained HTML. Synthetic two-shapes upload: 2 paths, 80 points, no browser errors. HTTP response: 200 with LieneCut title. These successes do not cover the discovered failure paths.

Not performed: physical printing/USB writes, full-history secret scanning, DAST/exploit testing, axe, screen-reader testing, hosted CI, or architecture sign-off. No secrets are copied into this report.
